# CopyPaste
A simple server and client apps for clipboard sync between any number of devices.
Multiple users can use the server, and each of them is isolated. The system uses HTTP, and then it can be used from any where, either by the client python software or by building a different software. For iPhones, one can use shortcuts to connect to the server, but for this solution, the user needs to run the shortcut on demand.
This is an experimentation project, and so, it's not documented since it's small and easy to understand.
